# Análisis de ventas de una ferretería

## Descripción del proyecto

Este proyecto consiste en analizar las ventas de una ferreteria, utilizando herramientas de análisis de datos para transformar información sin procesar en información útil para la toma de decisiones.

## Herramientas utilizadas

- **Python:** limpieza y transformación de datos.
- **SQL:** consultas y análisis de información.
- **Power BI:** creación de dashboard y visualización de resultados.

## Desarrollo del proyecto

1. Limpieza y preparación de los datos utilizando Python.
2. Análisis de la información mediante consultas SQL.
3. Desarrollo de un dashboard interactivo en Power BI.
4. Identificación de indicadores y principales resultados comerciales.

## Principales resultados

- Sucursal con mayor facturación: Córdoba (26,88%).
- Producto más vendido: Martillo (1.002 unidades).
- Categoría con mayor facturación: Herramientas manuales ($69.831.680).
- Medio de pago más utilizado: Transferencia.
